# Risorse grafiche opzionali

Il gioco funziona già senza file esterni. Inserisci qui eventuali texture e sprite CC0. Fonti consigliate: Kenney.nl e OpenGameArt, controllando la licenza del singolo pacchetto. Evita il caricamento delle texture da URL durante la partita: rende il gioco fragile e richiede connessione anche per la modalità offline.
